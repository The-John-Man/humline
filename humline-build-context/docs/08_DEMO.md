# Demo script

## 90 seconds

0–10: “A melody arrives before you know how to write it down. Humline turns that voice memo into something you can edit.”

10–25: Click Record and hum a short original phrase with clear gaps. Stop. Let the audience hear the original briefly.

25–40: Convert. Show the actual notes appearing. Explain that imperfect singing and imperfect detection are both editable.

40–60: Move one note and lengthen another. Play the Keys preset, then change to Pluck. The audience should hear the correction and timbre change.

60–75: Export MIDI. Open or parse the result in a prepared independent tool if available. Otherwise show a tested export confirmation and explain that the file can be opened in music software.

75–90: “It starts with your melody and ends with notes you control.” Mention local processing only if the implemented network behaviour supports that claim.

## Preparation

Test the actual microphone and output device, set comfortable volume, use headphones for rehearsal to avoid feedback, and keep a short original recording available. Load the app and any required assets before presenting. Disable distracting personal notifications yourself. Do not record bystanders without consent.

## Fallbacks

If live capture fails, use a previously recorded original hum and say it was prerecorded. If only the synthetic example is available, explicitly call it a synthetic example. Both must use the same conversion code. Never substitute prewritten note events and present them as successful live transcription.

If the detector makes a modest error, use that error to demonstrate editing. If conversion fails, show the honest error and retry with supported input. Do not claim the app can transcribe full songs or chords.

## Production story

Initial user: a hobby songwriter saving ideas. Next improvements, after the MVP: better human-voice transcription, persistent audio projects, licensed richer instruments, mobile capture, and export compatibility. A paid creative toolkit is a hypothesis to explore later, not evidence of demand.
